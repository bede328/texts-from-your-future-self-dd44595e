## The text

> Future you here. Stop saving the good towels for guests. The guests never came — and the towels are curtains now.

One funny text message from the future self, sent back to the present self:
the "good towels" saved for guests who never arrive end up as curtains —
a small domestic habit, reframed by the punchline into a whole life.

## How it works

`main.ts` writes that single line (113 characters, no trailing newline)
to `/output/entry.txt`.

```sh
node main.ts
cat /output/entry.txt
```
